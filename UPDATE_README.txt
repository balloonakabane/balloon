balloon パスワード設定・再設定機能の更新

【更新ファイル】
index.html
app.js

【アップロード手順】
1. このZIPを解凍する
2. GitHubの balloonakabane/balloon を開く
3. Code → Add file → Upload files から index.html と app.js をアップロード
4. Commit changes で保存
5. GitHub Pagesに反映後、アプリを再読み込みする

【追加される機能】
・ログイン画面：「パスワードを忘れた場合」（再設定メールを送信）
・設定画面：「パスワードを変更」（登録メールに再設定メールを送信）
・新規登録：「8文字以上」「英大文字」「数字」をチェック
・新規登録時の確認用パスワード欄
・パスワード表示／非表示

【注意】
・firebase-config.js は絶対に上書きしない（今回のZIPには含まれません）
・Firestoreルールは変更しない
・事前に設定していたballoonアイコンの参照を維持
・パスワード再設定はメールを受信できる本人だけが完了できる
・Firebaseの認証ポリシーが「英小文字」「記号」を必須としている場合は、それも満たしてください
・ログイン中のパスワード変更は「設定」タブから操作
