# balloon 🎈 — スマホで入力しやすい給与計算アプリ

**GitHub Pages + Firebase Authentication + Cloud Firestore**。静的サイトで公開でき、各ユーザーが自分の勤務記録だけを扱う個人利用型です。GitHub Pages単独ではログイン・クラウド保存はできません。

## まず試す

- 公開前でも `index.html` を静的Webサーバーで表示し、「👀 設定なしで試す（デモ）」を選べます。
- デモの記録はその**ブラウザの localStorage のみ**に保存。ほかの人や端末とは同期されません。ブラウザのデータ削除で消えます。
- ローカル開発はこのフォルダで `python -m http.server 8000` を実行して `http://localhost:8000` を開いてください。ZIPを展開せずに `index.html` を直接開くのは避けてください。
- 実際に複数ユーザーが自分のアカウントで使うには、下記Firebase設定をしてください。

## スマホ向けUI

1. **ホーム**：今月の給与、出勤日数、バック・罰金の集計。日付をタップして編集。前月／翌月、CSV出力。
2. **日別入力**：出勤・当欠を上部のボタンで切り替え。時給・出退勤・遅刻を入力。ドリンクはカテゴリーを選んで品目をタップ、＋／−で本数変更。「その他フード」は名前と販売金額を直接入力。画面下に見込み給与と保存ボタンを表示。
3. **メニュー**：ドリンク・フード・シャンパンの販売金額、バック率、固定バック額を各自で編集・追加・削除。
4. **設定**：標準時給を各自で設定。勤務入力時に上書きも可能。

**1日につき出勤または当欠1件**。同じ日を保存し直すと、その日の記録が更新されます。

## 計算仕様

- **勤務時間**：出勤時刻〜退勤時刻（日またぎ自動対応）から**中抜け同伴の無給分だけ**を引き、給与対象時間を**15分単位で切り上げ**ます。
- **遅刻**：入力した遅刻分数に対し、15分につき300円（切り上げ）。実際に出勤した時間から時給を計算するため、遅れた分の時給も発生せず、**別途この罰金**を計上します。
- **中抜け同伴**：1回2,000円バック。中抜けしていた時間は、入力した分数だけ実働から除きます。通常の休憩は差し引きません。
- **ドリンク／フード**：原則「販売金額×指定率」を1点あたり円単位四捨五入、またはメニューに記録された**固定バック額**を使います。
- **当日欠勤（当欠）**：**欠勤当日**が平日なら2,000円、土日祝日なら4,000円。罰金は**その次の出勤日**にまとめて計上し、月をまたいで繰り越します。複数回あれば合算。
- **10%控除**：`floor((時給分 + 各種バック + 同伴バック − 遅刻罰金 − 次回勤務に反映する当欠罰金) × 0.9)`。一日の計算を円単位で切り捨て、その日の金額を月間集計。マイナスの見込み額もありえます。
- **メニュー／時給変更**：当時の単価・率・時給を日別記録にコピーして保存します。編集のときは、その日の記録済み金額が基準です。
- **履歴修正と当欠罰金**：当欠や勤務日を追加・編集・削除すると、どの日に当欠罰金を充当するかが再計算されます。過去の勤務額が変わる場合があります。

### 祝日判定について

土日は自動判定。**2026〜2027年の祝休日**は内閣府公開の確定済み日付をプログラム内に収録しています。これ以外の年は、平日に当たる祝日を「祝日として扱う」で手動指定してください。公開資料が更新されたら `calculator.js` の `HOLIDAYS` に追加してください。

出典: [内閣府「国民の祝日について」](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)

## Firebaseの設定（本番利用に必須）

1. [Firebase Console](https://console.firebase.google.com/) でプロジェクトを作成し、料金プランは必要に応じて**Spark（無料）**を選択。
2. 「プロジェクトの設定」→「マイアプリ」→ **ウェブ（</>）** を登録。「firebaseConfig」の `apiKey`、`authDomain`、`projectId`、`appId` の値を、このフォルダの `firebase-config.js` に転記します。Webクライアントの設定値は公開される前提ですが、**サービスアカウントのJSONや管理者秘密鍵は絶対にGitHubへ置かない**でください。
3. Authentication → Sign-in method → **メール / パスワード** を有効化。
4. Firestore Databaseを有効化し、本番環境モードでデータベースを作成。
5. Firestore Database → ルールで、同梱 `firestore.rules` を丸ごと貼り付けて「公開」。**全員にread/writeを許可するテストルールは使用しない**でください。
6. GitHubに新しい**Public**リポジトリを作成し、ZIP内の `index.html`、`app.js`、`calculator.js`、`styles.css`、`firebase-config.js`、`firestore.rules`、`.nojekyll` 等のファイルをリポジトリ直下に配置（ZIPのままアップロードしない）。
7. GitHub → Settings → Pages → **Deploy from a branch** → `main` → `/(root)` → Save。
8. Firebase Authentication → Settings → **Authorized domains** に GitHub Pagesのホスト名 `ユーザー名.github.io` を追加（`https://`や`/リポジトリ`は含めない）。
9. 公開された `https://ユーザー名.github.io/リポジトリ名/` を開き、**新規登録**→日別入力→月間集計→別のユーザーでログインし記録が見えないことを確認。

公開後の更新は、GitHubのリポジトリへファイルを上書きコミットするだけです。**このバージョンはCSS・画像・画面文言を中心に更新したもので、Firestoreのデータ構造を変えていません。**GitHub Pagesの公開ソースは誰でも閲覧できるため、実データをコードやHTMLに書かないでください。

## データの安全性と制限

- Firestoreのパスは `users/{uid}/settings/profile` と `users/{uid}/entries/{YYYY-MM-DD}`。本人のアカウントだけが自分のデータを読み書きできるよう `firestore.rules` で制限しています。
- GitHub Pagesに保存されるのは静的HTML・CSS・JS。実際の勤務データは**Firebase**側です。
- 各ユーザーに対する管理者画面、勤怠承認、給与振込、税金・社会保険計算は**未実装**です。
- 料金は常に無料とは限らず、Firebaseの無料枠・利用規約を確認してください。
- 厳密な給与計算・賃金支払・罰金の適法性を保証するものではありません。特に勤務時間の切り上げ／切り捨てや罰金・賃金控除は雇用契約・労働法を確認してください。本アプリは**自己申告による見込み額**です。

## 構成

- `index.html` — 画面構造
- `styles.css` — 基本スタイル（既存機能用）
- `balloon-theme.css` — balloon のかわいいパステルデザイン（見た目のみ変更）
- `balloon-mark.svg`／`balloon-cluster.svg` — 風船のロゴ・イラスト
- `app.js` — UI、ログイン、保存、集計
- `calculator.js` — すべての給与計算ルール、祝日リスト、初期メニュー
- `firebase-config.js` — ユーザーが追記するFirebase設定
- `firestore.rules` — Firestore本人限定ルール
- `tests.mjs` — `node tests.mjs` で実行する計算テスト
